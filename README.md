# MusicTrainer

Приложение для тренировки музыкального слуха. Пользователь слышит интервал и подбирает
его на слух, вращая «невидимый джойстик» осциллографа; отклонение в центах пишется
в статистику. Звук не берётся из файлов, а генерируется процедурно (pygame + numpy).

## Структура

```
MusicTrainer/
├── src/                  Код приложения
│   ├── main.py           Точка входа
│   ├── core/             Звуковой движок, микшер, тембры, статистика
│   ├── exercises/        Логика упражнений, настройки, экраны упражнений
│   ├── screens/          Меню, джойстик, статистика, отладка
│   └── ui/               Базовые виджеты и элементы управления
├── docs/                 Документация (см. docs/CONTEXT.md)
├── tools/                Вспомогательные скрипты разработчика
├── p4a-recipes/          Рецепты python-for-android для сборки APK
├── buildozer.spec        Конфигурация сборки APK
└── Dockerfile            Образ для сборки APK
```

Файлы `exercise_settings.json`, `exercise_progress.json`, `data/` и `sessions/`
создаются приложением в рабочей директории и хранят пользовательские данные.

## Запуск на Windows

Требуется Python 3.11+ (проверено на 3.13).

```
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
```

Дальше достаточно запустить `run.bat` — двойным кликом или из терминала:

```
run.bat
```

Скрипт сам переходит в корень проекта и выставляет UTF-8 режим. Эквивалент
вручную:

```
set PYTHONUTF8=1
.venv\Scripts\python src\main.py
```

Запускать нужно **из корня проекта** — приложение сохраняет настройки и
статистику относительно текущей рабочей директории. `PYTHONUTF8=1` обязателен:
код печатает emoji в консоль, а без UTF-8 режима Windows-консоль в кодировке
cp1251 падает с `UnicodeEncodeError` ещё до старта.

## Проверка окружения

```
.venv\Scripts\python tools\check_imports.py
```

Скрипт по очереди импортирует все модули приложения и показывает, какой из них
не грузится. Внутри самого приложения есть экран **DIAGNOSTICS** с более
подробной самопроверкой (звук, виджеты, экраны).

## Сборка APK для Android

```
build_android.bat
```

Собирает APK в Docker-контейнере, результат кладёт в `bin/`. Нужен запущенный
Docker Desktop; первая сборка занимает 40–90 минут.

Быстрее — собрать в GitHub Actions (запускается автоматически при push) и
забрать готовый APK одной командой:

```
get_apk.bat install
```

Скрипт скачает последнюю успешную сборку в `bin/` и поставит её на
подключённый телефон. Нужен GitHub CLI, авторизованный через `gh auth login`.

Подробности, установка на телефон и история отказов сборки — в
[docs/ANDROID.md](docs/ANDROID.md).
