## Архитектура
**Многослойная архитектура с разделением на UI, бизнес-логику и звуковой движок**

### Слои:
- **UI:** Kivy (экраны, виджеты, осциллограф)
- **Бизнес-логика:** ExerciseEngine (упражнения, режимы)

- **Данные:** SettingsManager, ProgressManager

## Компоненты

### SoundEngine
**Файл:** `src/core/engine.py`
**Описание:** Звуковой движок с управлением старт/стоп

**Ключевые методы:**
- `start() - запуск генерации звука`
- `stop() - остановка генерации звука`
- `set_frequency(freq) - установка частоты`
- `set_volume(vol) - установка громкости`
- `get_sine_data() - получение данных для осциллографа`

**Особенности:**
- Плавное изменение частоты (ramp)
- Кроссфейд при смене частоты
- Поддержка 5 тембров
- Моно-режим
- Поиск свободного звукового канала

### ExerciseEngine
**Файл:** `src/exercises/engine/exercise_engine.py`
**Описание:** Движок управления упражнениями

**Ключевые методы:**
- `start_session() - начало сессии`
- `generate_task() - генерация задания`
- `start_adjustment() - начало настройки`
- `update_interval_frequency(freq) - обновление частоты`
- `check_answer(freq) - проверка ответа`
- `get_current_frequency() - получение текущей частоты`
- `get_sine_data() - получение данных для осциллографа`

**Режимы:**
- **melodic:** Мелодический режим (последовательное воспроизведение)
- **harmonic:** Гармонический режим (одновременное воспроизведение)

### ExerciseOscilloscope
**Файл:** `src/exercises/ui/exercise_oscilloscope.py`
**Описание:** Осциллограф для упражнений с суженным диапазоном частот

**Ключевые методы:**
- `update_visualization(dt) - обновление визуализации`
- `set_exercise_mode(enabled) - установка режима упражнения`
- `update_frequency_from_engine() - обновление частоты из движка`
- `_update_frequency(dt) - обновление частоты`

**Особенности:**
- Суженный диапазон частот
- Автоматический выбор движка для визуализации
- Поддержка упражнений и джойстика

### ExerciseScreen
**Файл:** `src/exercises/ui/exercise_screen.py`
**Описание:** Экран выполнения упражнения

**Ключевые методы:**
- `start_exercise() - запуск упражнения`
- `_create_oscilloscope() - создание осциллографа`
- `start_adjustment(instance) - начало настройки`
- `submit_answer(instance) - отправка ответа`

## Звуковая система

**Описание:** Гибридная система с тремя движками

### Движки:
- **sound_engine:** Основной движок для мелодического режима и джойстика
- **tonic_engine:** Движок для тоники в гармоническом режиме
- **interval_engine:** Движок для интервала в гармоническом режиме

### Режимы работы:

#### MELODIC:
- Звук через sound_engine, управление через ExerciseEngine
- Визуализация: sound_engine

#### HARMONIC:
- Тоника через tonic_engine, интервал через interval_engine
- Визуализация: interval_engine
- Управление: interval_engine через ExerciseEngine

**Каналы:** Используются разные каналы pygame для одновременного звучания

---

## Потоки данных

### Касания:
1. Пользователь касается осциллографа
2. on_touch_move() вычисляет новую частоту
3. _update_frequency() вызывает update_interval_frequency()
4. ExerciseEngine.update_interval_frequency() обновляет interval_engine
5. SoundEngine.set_frequency() меняет частоту звука

### Визуализация:
1. update_visualization() вызывается по таймеру
2. Получает данные из exercise_engine.get_sine_data()
3. Отображает данные на canvas

## Решенные проблемы

### Все движки использовали один канал pygame
**Решение:** Поиск свободного канала в SoundEngine.start()

### В гармоническом режиме осциллограф не показывал сигнал
**Решение:** Осциллограф получает interval_engine для визуализации

### В гармоническом режиме не менялась частота
**Решение:** Передача ExerciseEngine в осциллограф для управления
