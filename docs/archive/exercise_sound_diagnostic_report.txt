   Проблема: При настройке (подборе) звук пропадает
   Причина: В методе start_adjustment() не включается непрерывная генерация звука

   Решение: В методе start_adjustment() нужно:
   1. Запустить непрерывную генерацию звука для осциллографа
   2. Использовать sound_engine.start_continuous() или sound_engine.start()
   3. Для гармонического режима запускать тонику как фон

   Пример исправления:
   def start_adjustment(self):
       if not self.current_task:
           return
       mode = self.current_task['mode']
       tonic_freq = self.current_task['tonic_freq']
       interval_freq = self.current_task['interval_freq']
       self.stop_sound()
       if mode == 'harmonic':
           self.sound_engine.start_tonic(tonic_freq)
       else:
           self.sound_engine.start_continuous(interval_freq)
