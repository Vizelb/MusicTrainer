🏗️ 3. ОСНОВНЫЕ КЛАССЫ И МЕТОДЫ
--------------------------------------------------------------------------------

   🎵 SoundEngine (core/engine.py)
      Основной звуковой движок приложения

      🔧 Основные методы:
         - __init__(): Инициализация pygame микшера
         - start(): Запуск генерации звука
         - stop(): Остановка генерации звука
         - toggle(): Переключение старт/стоп
         - set_frequency(freq): Установка частоты
         - set_volume(vol): Установка громкости
         - next_timbre(): Следующий тембр
         - get_timbre_name(): Получение текущего тембра
         - get_sine_data(): Данные для осциллографа
         - get_diagnostics(): Диагностическая информация

   🎯 ExerciseEngine (exercises/engine/exercise_engine.py)
      Движок управления упражнениями

      🔧 Основные методы:
         - __init__(settings): Инициализация с настройками
         - start_session(): Начало сессии упражнений
         - generate_task(): Генерация задания
         - play_interval_full(): Воспроизведение интервала
         - start_adjustment(): Начало настройки (звук!)
         - update_interval_frequency(freq): Обновление частоты
         - stop_adjustment(): Остановка настройки
         - check_answer(user_freq): Проверка ответа
         - get_progress(): Получение прогресса
         - close(): Закрытие движка

   🖥️ ExerciseScreen (exercises/ui/exercise_screen.py)
      Экран выполнения упражнения

      🔧 Основные методы:
         - __init__(app): Инициализация экрана
         - start_exercise(): Запуск упражнения
         - start_adjustment(): Обработчик кнопки 'Начать подбор'
         - repeat_interval(): Повтор интервала
         - submit_answer(): Отправка ответа
         - next_task(): Следующее задание
         - exit_exercise(): Выход с сохранением прогресса

   ⚙️ ExerciseSettings (exercises/config/settings.py)
      Настройки упражнений

      🔧 Основные методы:

         - set_mode(mode): Установка режима
         - get_selected_intervals(): Выбранные интервалы

💡 7. РЕКОМЕНДАЦИИ ДЛЯ РАЗРАБОТКИ
--------------------------------------------------------------------------------

   1. При изменении звука проверяйте размерность массивов:
      - Для МОНО: 1D массив (N,)
      - Для СТЕРЕО: 2D массив (N, 2)

   2. При добавлении новых тембров обновите timbre.py

   3. При изменении настроек упражнений:
      - Добавьте новый параметр в ExerciseSettings
      - Обновите to_dict() и from_dict()

   4. При сборке APK:
      - Используйте python3==3.10.12
      - Добавьте pygame в requirements
