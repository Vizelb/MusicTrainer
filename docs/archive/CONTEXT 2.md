## АРХИТЕКТУРА
### Звуковая система:
- **sound_engine:** Основной движок для мелодического режима
- **tonic_engine:** Движок для тоники в гармоническом режиме
- **interval_engine:** Движок для интервала в гармоническом режиме
- **Каналы:** Используются разные каналы pygame
- **Частота дискретизации:** 44100 Гц

### Система упражнений:
- **Режимы:** melodic, harmonic
- **Интервалов:** 22
- **Диапазон тоники:** C3 - C5

### UI:
- **Фреймворк:** Kivy
- **Экраны:** menu, joystick, exercise, settings, info, debug

## ПРИНЯТЫЕ РЕШЕНИЯ
| Решение | Причина |
|---------|---------|
| Использовать pygame | KivySoundLoader не работает на Android |
| МОНО-режим звука | 1 канал, одномерные массивы |
| Ленивая инициализация SoundEngine | Избежать ошибок до создания окна |
| Разделение на 3 звуковых движка | Для правильной работы гармонического режима |
| Передача ExerciseEngine в осциллограф | Для управления частотой через упражнения |
| MockSoundEngine для тестов | Изоляция логики от звука |
