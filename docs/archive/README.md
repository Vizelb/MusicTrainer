## Отчёты диагностики

`*_report.txt`, `audit_report.*` — вывод разовых диагностических скриптов от 11–14 августа 2026.
Это снимки состояния кода на тот момент, а не документация. Часть находок в них
уже неактуальна: например, `audit_report.txt` сообщает об отсутствии `buildozer.spec`,
`data/` и `exercises/ui/stats_widget.py`, которые в проекте есть.
