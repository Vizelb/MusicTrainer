## ПРИНЯТЫЕ РЕШЕНИЯ

| Решение | Причина |
|---------|---------|
| **pygame** вместо KivySoundLoader | KivySoundLoader не работает на Android |
| **МОНО-режим звука** | 1 канал, одномерные массивы |
| **AudioMixer** | Централизованное управление звуком |
| **3 звуковых движка** | Для правильной работы гармонического режима |
| **Непрерывный режим** | Пользователь сам завершает сессию |
| **Хранение в JSON** | Простота и человекочитаемость |
