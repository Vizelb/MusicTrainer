# КОНТЕКСТ РАЗРАБОТКИ: СТАТИСТИКА И НЕПРЕРЫВНЫЙ РЕЖИМ

## ОБЩАЯ ИНФОРМАЦИЯ

| Параметр | Значение |
|----------|----------|
| Проект | MusicTrainer |
| Версия | v5.8 |
| Дата создания | 2026-08-14 |
| Статус | Планирование |

## ОПИСАНИЕ ЗАДАЧИ

Переход от сессионного режима (10 заданий) к непрерывному режиму упражнений.
Создание системы сбора и визуализации статистики в реальном времени.

## КЛЮЧЕВЫЕ РЕШЕНИЯ

| Решение | Причина |
|---------|---------|
| Хранение в JSON | Простота, человекочитаемость, достаточно для текущих объёмов |
| Непрерывный режим | Пользователь сам решает, когда завершить упражнение |
| Запись после каждой попытки | Мгновенное сохранение прогресса |
| Отдельная сессия в памяти | Для отображения текущего прогресса |
| Фильтрация в памяти | Быстрая работа с небольшими объёмами данных |

## СТРУКТУРА ДАННЫХ

### Глобальная статистика (statistics.json)

```json
{
  "малая_терция": {
    "size_cents": 300,
    "history": [
      {
        "deviation": -5.2,
        "abs_deviation": 5.2,
        "timestamp": "2026-08-14T10:00:00",
        "mode": "melodic",
        "direction": "up",
        "tuning": "natural"
      }
    ],
    "total_attempts": 157,
    "last_updated": "2026-08-14T10:00:00"
  }
}
```

```json
{

  "end_time": null,

    "mode": "harmonic",

  },
  "attempts": [],
  "summary": {
    "total": 10,
    "correct": 7,
    "avg_deviation": -3.2
  }
}
```

## ДЕТАЛИ ЭТАПОВ

### ЭТАП 1: Обновление StatisticsManager

**Файл:** `core/statistics.py`

**Изменения:**
- Создание нового модуля с нуля
- Метод `record_attempt()` для записи попыток
- Управление сессией: `start_session()`, `end_session()`
- Фильтрация данных по интервалу, режиму, периоду
- Расчёт статистики: среднее, bias, тренд

### ЭТАП 2: Интеграция с ExerciseEngine

**Файл:** `exercises/engine/exercise_engine.py`

**Изменения:**
- Импорт `stats_manager` из `core.statistics`
- Вызов `stats_manager.record_attempt()` в `check_answer()`
- Передача всех параметров: интервал, отклонение, режим, направление
- Создание сессии при старте упражнения
- Завершение сессии при выходе

### ЭТАП 3: Удаление ограничения на 10 заданий

**Файлы:** `exercise_engine.py`, `exercise_screen.py`, `settings.py`

**Изменения:**
- Убрать проверку `task_index >= total_tasks`
- Убрать `tasks_per_session` из настроек
- Убрать авто-завершение сессии
- Добавить кнопку "Завершить сессию"
- Добавить отображение прогресса сессии

### ЭТАП 4: Создание экрана статистики

**Файлы:** `screens/stats_screen.py`, `exercises/ui/stats_widget.py`

**Изменения:**
- Панель фильтров: интервал, режим, движение, строй, период
- Виджет графика тренда на Canvas
- Отображение статистики: попытки, среднее, bias, тренд
- Обновление при изменении фильтров

### ЭТАП 5: Интеграция в навигацию

**Файлы:** `screens/menu_screen.py`, `main.py`

**Изменения:**
- Кнопка "Статистика" в главном меню
- Регистрация экрана в `main.py`
- Переходы между экранами

### ЭТАП 6: Тестирование

**Проверки:**
- Запись статистики после каждой попытки
- Непрерывный режим (20+ заданий)
- Все комбинации фильтров
- Отображение графика
- Навигация между экранами
