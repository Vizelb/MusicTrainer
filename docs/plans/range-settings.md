## 2. КЛЮЧЕВЫЕ РЕШЕНИЯ

1. Настройки применяются при старте упражнения (не live)
2. Диапазон настройки автоматически корректируется, если меньше стартового
3. Начальная частота генерируется случайно в пределах start_range
4. Без предупреждений - только автоматическая корректировка
5. Настройки общие для обоих режимов

## 3. ТЕХНИЧЕСКАЯ СПЕЦИФИКАЦИЯ

### 3.1. НОВЫЕ НАСТРОЙКИ (ExerciseSettings)

self.tuning_range = 400  # Диапазон настройки (50-1200)
self.start_range = 400   # Диапазон старта (50-1200)

**Методы:**
- set_tuning_range(value) - устанавливает, корректирует если < start_range
- set_start_range(value) - устанавливает, корректирует tuning_range если нужно

### 3.2. НОВЫЕ СЛАЙДЕРЫ (SettingsScreen)

- Слайдер 1: **'Диапазон настройки'** (50-1200, шаг 10)
- Слайдер 2: **'Диапазон старта'** (50-1200, шаг 10)

**Логика:** при изменении start_range > tuning_range → автоматически поднимаем tuning_range

## 6. ТЕСТ-КЕЙСЫ

1. Базовый случай: tuning_range=400, start_range=400 → частота в пределах ±400 центов
2. start_range > tuning_range: start_range=800, tuning_range=400 → tuning_range становится 800
3. Границы глобального диапазона: Эталон 120 Гц, start_range=800 → нижняя граница 100 Гц
4. Смена режимов: Настройки работают одинаково для melodic и harmonic
5. Случайная частота: При каждом нажатии 'Начать подбор' частота разная
6. Повтор задания: При новом задании генерируется новая случайная частота
